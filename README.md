# Pizzería La Esquina — proyecto de portafolio

Sitio web para una pizzería de barrio **ficticia** de General Paz, Córdoba.

**Problema que resuelve:** la pizzería atendía pedidos solo por Instagram y apps de delivery, y los clientes preguntaban todo el tiempo por el menú y los horarios. Necesitaba una web rápida y adaptada a celulares donde mostrar el menú actualizado, su ubicación y un botón para pedir directo por WhatsApp, sin pagar comisión a terceros.

## Pantallas
- `index.html` — Inicio: portada, horarios con aviso de abierto/cerrado, destacadas, cómo pedir y ubicación.
- `menu.html` — Menú: categorías, precios media/entera, platos sin TACC y un pedido que se arma solo y se envía por WhatsApp.

## Tecnologías
HTML, CSS y JavaScript sin frameworks. Responsive, con modo oscuro automático.

## Publicarlo en GitHub Pages
1. Crear un repositorio y subir estos archivos.
2. Settings → Pages → Branch `main` / carpeta raíz → Save.

Para usarlo con un local real, poner su número en la constante `WHATSAPP` de `script.js`.
